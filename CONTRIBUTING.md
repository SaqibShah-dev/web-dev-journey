# Contributing to web-dev-journey

Thanks for your interest in contributing! This project is a learning & practice collection — small improvements are welcome (typos, examples, docs, exercises, tiny bugfixes).

How to contribute
1. Fork the repository.
2. Create a branch from main: `git checkout -b fix/short-description`
   - Branch naming guidelines: use `fix/`, `feat/`, or `chore/` prefixes, followed by a short slug.
3. Make your changes.
4. Commit with a clear message (imperative present tense): `git commit -m "docs: clarify Netflix landing page instructions"`
5. Push your branch and open a Pull Request against the repository's `main` branch.

PR checklist
- [ ] My code follows the repository style (see note below).
- [ ] I updated documentation or README if relevant.
- [ ] I tested changes locally where applicable.
- [ ] The PR description explains why the change is needed and what it does.

Preferred contribution types (fast review)
- Documentation improvements (README, project-level how-to-run).
- Small bug fixes in examples or exercises.
- Additions to learning resources (short notes, small code samples).
- Small UI/HTML/CSS fixes in the example projects.

Coding style
- Keep JavaScript examples simple and readable (ES6+).
- For CSS/HTML examples, prefer semantic HTML and small, focused styles.
- Keep changes minimal and focused to make review quick.

Running or previewing examples
- Most pages are static HTML/CSS — open the file in your browser or use VS Code Live Server for live reload.
- If a project has a package.json, run `npm install` then `npm run start` or `npm run dev` (check the project README for specific commands).

Reporting issues
- Use the repository Issues to report bugs or propose improvements.
- When opening an issue, include:
  - A short descriptive title.
  - Steps to reproduce (if applicable).
  - Expected vs actual behavior.
  - Screenshots or code snippets when helpful.

Code of conduct
- Be respectful and constructive. This repository follows a friendly, inclusive tone. If you want a formal code of conduct added, I can include the Contributor Covenant.

Thanks again — small contributions make this learning resource better for everyone!
