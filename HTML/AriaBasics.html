Mastering WAI-ARIA Basics ♿

A clean, beginner-friendly guide to making web components accessible to screen readers.

1. aria-label

The Whisperer: Use this when an element has no visible text (like an icon button). It tells screen readers exactly what text to read out loud.
← Hover or inspect this icon button

2. aria-expanded

The Gatekeeper: Tells screen readers if expandable content (like a dropdown menu or accordion) is currently open (true) or closed (false).
  • Dashboard
  • Settings
  • Logout

3. aria-describedby

The Detailer: Connects an input element to a separate text container containing instructions or warnings. Screen readers read the input label first, then this description.
Username must be lowercase and contain at least one number.

4. aria-hidden

The Cloaking Device: Tells screen readers to ignore decorative elements completely. Emojis and stars can sound messy or repetitive when read aloud.

The Megaphone: Forces screen readers to immediately announce changes in dynamic content updated by Javascript (without page reloads).
