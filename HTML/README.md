# 📝 Phase 1: HTML Fundamentals

Welcome to the **HTML Fundamentals** practice lab! HTML (HyperText Markup Language) is the skeleton of the web. It defines the structure and meaning of web content.

In this folder, you will find files demonstrating how to write clean, semantic, and modern HTML5 markup that is search-engine optimized (SEO) and accessible to screen readers.

## 🧠 Core Learning Objectives

Before moving on to **Phase 2 (CSS Box Model)**, ensure you are comfortable with these standard HTML concepts:

1. **Semantic HTML:** Understanding why `<header>`, `<main>`, and `<footer>` are preferred over using generic `<div>` wrappers for everything (SEO, accessibility, and clean markup).
2. **Block vs. Inline:** Knowing that block elements (like `<div>`, `<p>`, `<h1>`) start on a new line and take up full width, whereas inline elements (like `<span>`, `<a>`, `<strong>`) only take up as much space as their contents.
3. **Responsive Viewport:** Knowing why `<meta name="viewport" content="width=device-width, initial-scale=1.0">` is critical for mobile screens.
4. **Form Attributes:** Knowing the role of `action`, `method`, `type` (email, password, text), and linking input elements to their description labels using the `for` and `id` properties.
