# 🎬 Netflix Landing Page Clone

A visually stunning, pixel-perfect, and fully responsive clone of the **Netflix Landing Page** built with semantic **HTML5** and modern, vanilla **CSS3** (using custom variables, CSS Grid/Flexbox, fluid typography, and transitions).

---

##  Features

- ** Fully Responsive Design**: Seamless viewing experience across mobile, tablet, and desktop screens using custom fluid layout strategies and `clamp()`.
- ** Animated Floating Input Labels**: The email signup input features a modern, animated floating label that lifts when focused or filled.
- ** Trending News Section**: A dynamic movie card grid with a stylish scale-up hover effect and a sequential numbering layout (1-10) similar to Netflix's trending carousel.
- ** Modern Aesthetics**: Includes custom gradient overlays, responsive red-line section dividers with glowing linear gradients, and a sleek dark mode theme matching Netflix's brand identity.
- ** Accordion FAQs**: Toggleable Frequently Asked Questions section built with HTML5 `<details>` and `<summary>` elements, custom-styled with clean expand/collapse animations and inline SVG indicators.
- ** Language Selector Dropdown**: Customized selection menu allowing multi-lingual selection styling.
- ** Lightweight & Pure**: 100% pure HTML & CSS with zero external library dependencies, ensuring blazing fast load times.

---

##  Tech Stack & Concepts Used

- **HTML5 Semantic Elements** (`<header>`, `<main>`, `<footer>`, `<details>`, `<summary>`)
- **CSS Custom Variables (Design Tokens)** for colors, overrides, and theme values.
- **CSS Flexbox & CSS Grid** for fluid grid alignments and responsive cards.
- **Fluid Typography & Sizing** using CSS `clamp()` and `minmax()` functions.
- **Micro-interactions** (transitions on buttons, hover states, scaling list cards).
- **Inline SVGs** for sharp, scalable vector graphics icons.

##  How to Run Locally

1. **Clone the project** or download the ZIP folder.
2. Ensure you have the `images` directory in the same folder as the HTML and CSS files.
3. Open `Netflix-Landing-page.html` directly in any web browser (Chrome, Edge, Safari, Firefox).
   - *Alternative:* Use the VS Code extension **Live Server** to run it on a local development server with auto-reload capabilities.
