# Web Development Learning Repository

Welcome to my Web Development learning repository! This project documents my journey as a BS Artificial Intelligence student (6th semester) learning full-stack web development. I am currently focusing on the core pillars of the web: HTML and CSS, on my path to becoming a MERN stack developer.

This repository is designed to be a learning resource for myself and other new students starting their web development journey. 

## Repository Structure

The repository is organized by topics and contains various practice files and mini-projects to demonstrate key concepts in HTML and CSS.

### 1. HTML (`/HTML`)
This directory contains foundational HTML practice files covering essential elements:
- **`Forms.html`**: Creating user input forms, labels, inputs, and text areas.
- **`LinksImages.html`**: Embedding images and creating hyperlinks.
- **`Lists.html`**: Unordered and ordered lists.
- **`MetaTags.html`**: Understanding head meta tags for SEO and responsive design.
- **`Multimedia.html`**: Embedding audio and video.
- **`Tables.html`**: Structuring tabular data using HTML tables.
- **`TextTags.html`**: Formatting text with headings, paragraphs, and semantic tags.
- **`divContainer.html`**: Using `div` and `span` elements to group content.
- **`practice_project.html` & `simple_page_layout.html`**: Putting it all together to create basic, structured web pages (e.g., a simple portfolio page).

### 2. CSS (`/CSS`)
This directory contains styling practices, divided into core layout concepts:
- **Box Model (`/CSS/Box Model`)**: 
  - Explores the fundamentals of CSS layout: margins, borders, padding, and content.
  - Contains multiple tasks and approaches (`Box_Model_Task1.html` to `Box_Model_Task5.html`, `Approach1.html`, etc.) demonstrating how elements interact.
  - Includes notes on common issues like margin collapse (`solution_for_margin_collapse.txt`).

- **Flexbox (`/CSS/Flex Box`)**:
  - A deep dive into the Flexible Box Layout module.
  - Files cover specific properties: `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, `flex-grow`, `flex-shrink`, etc.
  - Practical tasks like creating navbars (`Navbar_task.html`), card grids (`card_grid_task2.html`), and full-page layouts (`Full_page_layout.html`) using Flexbox.

### 3. Root Files
- **`simple_web_page.html`**: A clean, semantic HTML structure acting as a basic template or introductory page.
- **`images/`**: Contains assets used across the HTML and CSS practice files.

##  How to Use This Repository

If you are a new student learning web development, you can use this repository to:
1. **Explore Concepts:** Open the individual HTML files in your browser to see how different HTML tags render.
2. **Review Code:** Open the files in your text editor (like VS Code) to study the syntax and structure.
3. **Practice Layouts:** Look closely at the CSS directory to understand how the Box Model and Flexbox are used to position elements on a page.
4. **Build Upon:** Use `practice_project.html` as a starting point to create your own personal portfolio.

- **CSS3:** Selectors, Box Model, Flexbox layout module.
