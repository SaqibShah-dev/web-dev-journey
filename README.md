# web-dev-journey

A beginner-friendly collection of notes, practice files, and code examples for learning full-stack web development (HTML, CSS, JavaScript, and MERN topics). This repo is structured as a set of small, focused learning modules and example projects you can open and run locally.

What’s included
- CSS labs and capstone projects (Netflix Landing Page, responsive galleries)
- JavaScript/Express small examples and route fundamentals
- MERN-style example projects (Pixelcraft marketplace, chat app)
- Machine learning practice projects (Speech emotion recognition, etc.)

Quick start
1. Clone the repo:
   git clone https://github.com/SaqibShah-dev/web-dev-journey.git
2. Browse the folders and open static examples (many are plain HTML/CSS and can be opened directly in a browser).
3. For projects with package.json:
   - cd into the project folder
   - install: `npm install`
   - run: `npm run dev` or `npm start` (follow the per-project README for exact commands)
